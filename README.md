# 📊 SMC & Trendline Confluence Analyzer

Aplicação Web interativa desenvolvida em Python e Streamlit para análise e backtesting de confluência entre **5 Indicadores Técnicos** (Order Blocks SMC, LTA/LTD, Sessões DST e Médias Móveis).

## 🚀 Funcionalidades
- **Upload de CSV:** Compatível com dados exportados do TradingView e MetaTrader.
- **Métricas:** Win Rate (%), Factor de Lucro, Lucro/Prejuízo Total.
- **Visualização:** Gráfico interativo de velas (Candlestick) e Curva de Capital (Equity Curve).
